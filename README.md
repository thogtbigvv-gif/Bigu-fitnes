# Bigu-fitnes — Дасгалын тэмдэглэл

Өдөр тутмын дасгалын төлөвлөгөөг харуулж, дасгал бүрийг гүйцэтгэх тутам todo list
шиг тэмдэглэдэг **утсанд зориулсан** вэб апп.

- Framework, npm, build step алга — зөвхөн HTML + CSS + ES modules.
- Гадны CDN, library, font холбоогүй. Бүх зүйл repo дотроо.
- Backend алга. Бүх өгөгдөл хөтчийн `localStorage` дээр.

## Дэлгэцүүд

| Таб | Юу харуулах |
| --- | --- |
| **Өнөөдөр** | Огноо, өдрийн нэр, гүйцэтгэлийн progress, дасгалын жагсаалт. Дасгал дээр дархад сет тус бүрийг тусад нь тэмдэглэнэ. Бүгд дуусахад "дууслаа" төлөв гарна. Амралтын өдөр бол тусдаа энгийн дэлгэц. |
| **Долоо хоног** | Даваа–Ням 7 өдрийн товч тойм, аль өдөр биелсэн эсэх. |
| **Түүх** | Сүүлийн 30 өдрийн хийсэн / хийгээгүй / амралт. |

## Яаж ажиллуулах

Апп нь `data/program.json`-ыг `fetch`-ээр уншдаг тул `index.html`-ийг файлаар шууд
нээвэл (`file://`) хөтчийн аюулгүй байдлын дүрмээр ажиллахгүй. Локал сервер хэрэгтэй:

```sh
# repo-гийн үндсэн хавтсанд
python3 -m http.server 8000
```

Дараа нь утас эсвэл хөтчөөс `http://localhost:8000/` руу орно.
(Chrome DevTools дээр төхөөрөмжийн горимыг 360–430px өргөнтэй тохируулж үзэхэд тохиромжтой.)

**GitHub Pages:** repo-г Pages дээр нийтэлхэд ямар ч тохиргоо шаардахгүй. Бүх зам
харьцангуй (`./css/...`, `./js/...`, `./data/...`) тул `/gym-tracker/` гэх мэт дэд
замд байрлуулсан ч ажиллана.

## Хөтөлбөрөө яаж солих

Бүх дасгал `data/program.json` дотор байдаг. **Код руу юу ч бичих шаардлагагүй** —
энэ нэг файлыг л засна.

### Өдрийн id ↔ гарагийн харгалзаа

Өнөөдрийн өдрийг **гарагийн дугаараар, орон нутгийн цагаар** тодорхойлно:

| id | Гараг | Одоогийн хөтөлбөрт |
| --- | --- | --- |
| `d1` | Даваа | Нуруу + Бицепс |
| `d2` | Мягмар | Мөр + Трицепс |
| `d3` | Лхагва | **Амралт** |
| `d4` | Пүрэв | Хөл + Хэвлий |
| `d5` | Баасан | Нуруу (зузаан) + Дельта |
| `d6` | Бямба | Цээж + Гар |
| `d7` | Ням | **Амралт** |

Өөрөөр хэлбэл `d1` бол үргэлж Даваа. Дасгалуудыг өөр гараг руу зөөх бол
тухайн `dN` дотор байгаа `exercises`-ийг зөөнө — id-г нь солихгүй.

### Файлын хэлбэр

```json
{
  "version": 1,
  "name": "Өргөн мөр, бүтэн нуруу",
  "restDays": ["d3", "d7"],
  "days": [
    {
      "id": "d1",
      "title": "Нуруу + Бицепс",
      "exercises": [
        { "id": "e101", "name": "Bent-over barbell row", "sets": 4, "reps": "8-10", "rest": 150, "note": "Нуруугаа бөхийлгөхгүй" }
      ]
    },
    { "id": "d3", "title": "Амралт", "exercises": [] }
  ]
}
```

- `days` дотор **7 өдөр** байна, `d1`-ээс `d7` хүртэл. Амралтын өдөр ч бас
  жагсаалтад орно, зүгээр `"exercises": []` гэж үлдээнэ.
- `restDays` дотор бичсэн id-тай өдөр → амралтын дэлгэц. (Дасгал нь хоосон
  байвал ч мөн адил амралт гэж тооцно.)
- **Дасгалын нэрийг орчуулах шаардлагагүй.** Заалны яриа хэлээр латин/монгол
  холимог байх нь хэвийн — `"Өргөн бариултай таталга / Lat pulldown"` гэх мэтээр
  бичсэн нэр яг тэр хэвээрээ дэлгэц дээр гарна.
- Дасгалын `id` бол хадгалагдсан тэмдэглэгээний холбоос. **Нэр, сет, давталт,
  амралтыг чөлөөтэй солиж болно**, гэхдээ `id`-г солих юм бол тухайн дасгалын
  хуучин тэмдэглэгээ таарахаа болино. (Одоогийн хөтөлбөрт `e101…e107` = d1,
  `e201…` = d2 гэх мэтээр өдрөөрөө бүлэглэсэн.)
- `reps` бол текст — `"8-10"`, `"5"`, `"45 сек"` бүгд болно.
- `rest` бол секундээр, `0` бол харуулахгүй.
- `note` хоосон байвал картан дээр гарахгүй.

## Дизайн

Бүх өнгө, зай, фонтын хэмжээ `css/base.css`-ийн `:root` дотор хувьсагчаар байна.
Бусад CSS файл зөвхөн `var()`-оор л уншина — шууд утга бичихгүй.

- **Дэвсгэр 3 давхарга:** `--bg-1 #0B0B0C` → `--bg-2 #141416` → `--bg-3 #1C1C1F`.
  Давхаргыг зөвхөн дэвсгэрийн зэрэглэлээр ялгана — `box-shadow` ашиглахгүй
  (харанхуй дэвсгэр дээр сүүдэр харагддаггүй). Gradient, blur, тунгалаг давхарга
  бас байхгүй.
- **Текст:** `--fg #F2F2F3`, `--fg-2 #9A9AA0`, `--fg-3 #5C5C63`.
- **Акцент өнгөгүй:** `--accent #DEDEE3` (зөөлөн саарал). Идэвхтэй таб,
  progress bar, гүйцэтгэсэн сетийн тэмдэглэгээ дээр л хэрэглэнэ. Өнгөт акцент
  байхгүй тул харанхуй заалд нүд барахгүй; статус нь саарлын зэрэглэл,
  жин, тунгалагаар ялгарна.
- **Улаан (`--danger`)** зөвхөн алдаа ба устгах дээр.
- **Зааг:** `--line rgba(255,255,255,0.08)`.
- **Зай:** зөвхөн 4px-ийн үржвэр — `--s1 4` … `--s8 32`. Хажуугийн зай 16px,
  дасгалын мөр хоорондоо 8px.
- **Фонт:** системийн стек, гадны фонт татахгүй. Хэмжээний шат
  **28 / 20 / 16 / 14 / 12px**, дунд хэмжээ байхгүй. Бүх тоо
  `font-variant-numeric: tabular-nums` (`.num` класс).
  Гарчигт `letter-spacing: -0.02em`, 12px шошгонд `+0.04em` + том үсэг.
- **Булан:** 8px / 12px. Илүү дугуйрахгүй.
- **Хөдөлгөөн** — бүгд `cubic-bezier(0.2, 0, 0, 1)`, богино:
  `--t-tap 140ms` (тэмдэглэх), `--t-tab 180ms` (таб ба дэлгэц солих),
  `--t-open 200ms` (сет задрах), `--t-bar 280ms` (progress гүйх).
  Bounce, spring байхгүй. `prefers-reduced-motion: reduce`-ийг хүндэтгэнэ.
  Тэмдэглэх хөдөлгөөн зөвхөн **дөнгөж дарсан** мөр/товч дээр тоглоно
  (`is-flash`), бусад нь чимээгүй шинэчлэгдэнэ.
- Эмодзи ашиглахгүй. Доод navigation нь icon + текст, идэвхтэй табын
  2px заагч табаас таб руу гүйнэ.

## Хадгалалт

Түлхүүр: `gym:state_v1` (namespace нь `gym:`). Бүх өгөгдөл нэг түлхүүр дор JSON-оор.

```json
{
  "version": 1,
  "sessions": {
    "2026-08-18": {
      "date": "2026-08-18",
      "dayId": "d1",
      "done": 3,
      "total": 7,
      "completedAt": "2026-08-18 19:42",
      "sets": { "e101": [true, true, false, false] }
    }
  }
}
```

- Огноо **зөвхөн орон нутгийн цагаар** `"YYYY-MM-DD"`. `toISOString()` хаана ч
  ашиглаагүй — цагийн бүсийн шилжилт гарахгүй.
- `version` талбар + `migrate()` байгаа тул схем солигдоход хуучин өгөгдөл эвдэрэхгүй.
  Танихгүй өгөгдөл устахгүй, `gym:backup_*` болж үлддэг.
- Өдрийн үр дүн `{ date, dayId, done, total, completedAt }` цэвэр бүтэцтэй.
  `storage.getDayResult(date)` шууд үүнийг буцаана — XP гүүр нэмэхэд бэлэн.
  (`js/data.js` дотор `calcXp()` дүрэм бий, гэхдээ **одоохондоо хаашаа ч илгээхгүй**.)

### Хуучин өгөгдөл цэвэрлэх

`data/program.json`-ыг сольсны дараа хуучин тэмдэглэгээ шинэ хөтөлбөртэй таарахаа
болино (дасгалын `id` өөр болсон, өдөр амралт болсон гэх мэт). Үүнийг **гараар
хийх шаардлагагүй** — апп ачаалах бүрд `storage.reconcile()` ажиллаж:

- хөтөлбөрөөс алга болсон өдрийн бичлэгийг устгана,
- одоо амралт болсон өдрийн бичлэгийг устгана,
- байхгүй болсон дасгалын сет тэмдэглэгээг хаяна,
- сетийн тоо өөрчлөгдсөн бол уртыг нь тааруулна,
- `done` / `total` / `completedAt`-ыг дахин тооцно,
- ганц ч сет үлдээгүй бол тухайн өдрийг бүхэлд нь устгана.

Шинэ хөтөлбөртэй таарч байгаа тэмдэглэгээ хэвээрээ үлдэнэ.

Бүгдийг нь цэвэрлэхийг хүсвэл **Түүх** дэлгэцийн доод талд *"Бүх тэмдэглэгээг
устгах"* товч бий. Санамсаргүй дарахаас сэргийлж хоёр алхамтай — эхний дарахад
баталгаажуулалт болж хувирна, өөр таб руу шилжихэд тайлагдана. Устгасны дараа
буцаах боломжгүй.

## Одоохондоо байхгүй зүйлс

Нэвтрэлт, серверт хадгалах, график, жин/давталт бүртгэх, Summer Project руу XP
илгээх гүүр — эдгээр нь одоогийн хамрах хүрээнд ороогүй.
